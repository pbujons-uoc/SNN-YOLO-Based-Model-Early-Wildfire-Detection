# Graphics Explanation and Input Expectations

This folder contains scripts to compare the training performance and energy consumption of different object detection models (e.g., YOLOv8, SpikeYOLO, VanillaCNN).

## Scripts
- **`compare_models.py`**: The main script to generate comparison plots.

## Input Expected
The script expects a root directory containing subdirectories for each model.
Inside each model's subdirectory, it looks for:
1.  **`results.csv`**: The standard training log files generated by YOLO (Ultralytics) or compatible training scripts.
    *   **Required Columns**: `epoch`, `metrics/mAP50(B)`, `metrics/mAP50-95(B)`, `train/box_loss`, `train/cls_loss`, `val/box_loss`, `val/cls_loss`.
2.  **`emissions.csv`** (Optional): Energy consumption logs generated by `codecarbon`.
    *   **Required Columns**: `epoch` (or index implied), `emissions`, `duration`.

### Example Directory Structure
```
results_train_all/
├── yolov8/
│   ├── results.csv
│   └── emissions.csv
├── spikeyolo_latency/
│   ├── results.csv
│   └── emissions.csv
└── ...
```

## Generated Graphics and Explanation

The script generates the following charts to provide a comprehensive comparison:

### 1. **mAP50 Comparison (`compare_mAP50.png`)**
*   **What it shows**: The Mean Average Precision at IoU threshold 0.5 over epochs.
*   **Why**: This is the standard metric for object detection accuracy. Comparing these curves shows which model learns faster and reaches a higher peak performance.
*   **Input**: `metrics/mAP50(B)` from `results.csv`.

### 2. **mAP50-95 Comparison (`compare_mAP50-95.png`)**
*   **What it shows**: The Mean Average Precision averaged over IoU thresholds 0.5 to 0.95.
*   **Why**: A stricter metric than mAP50. It indicates how precise the bounding boxes are. High mAP50 but low mAP50-95 implies the model finds objects but with loose localization.
*   **Input**: `metrics/mAP50-95(B)` from `results.csv`.

### 3. **Training & Validation Loss (`compare_losses_box.png`, `compare_losses_cls.png`)**
*   **What it shows**: The Box Regression Loss and Class Loss over epochs for both training and validation sets.
*   **Why**:
    *   **Box Loss**: How well the model localizes objects.
    *   **Class Loss**: How well the model properly classifies objects (Fire vs Smoke).
    *   **Train vs Val**: divergence typically indicates overfitting.
*   **Input**: `train/box_loss`, `train/cls_loss`, `val/box_loss`, `val/cls_loss`.

### 4. **Energy Consumption (`compare_energy_total.png`, `compare_energy_efficiency.png`)**
*   **What it shows**:
    *   **Total Energy**: Cumulative CO2 emissions (kg) or Energy (kWh) used during training.
    *   **Efficiency**: mAP per unit of energy (mAP / kWh).
*   **Why**: Critical for evaluating Green AI goals. A model might be slightly less accurate but significantly more energy-efficient, making it preferable for edge deployment or sustainable AI.
*   **Input**: `emissions` and `duration` from `emissions.csv`.

## Usage
Run the script from the root/code directory:
```bash
python benchmarking_trains/compare_models.py --root results_train_all
```
